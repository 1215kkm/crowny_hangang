## 1. 제작 의도 (Why)

### 배경
한강은 매년 수천만 명이 방문하는 서울의 대표 공공 공간이다.
치맥, 피크닉, 러닝, 야경 등 이미 사람들이 모여서 활동하는 곳인데,
**"옆에 있는 사람"과 자연스럽게 연결되는 방법이 없다.**

### 문제 정의
| 기존 문제 | 우리의 해결 |
|-----------|------------|
| 소개팅/매칭앱은 온라인 중심 → 오프라인 전환 부담 | **이미 같은 장소에 있는 사람**을 연결 (오프라인 우선) |
| 동호회/소모임은 사전 기획 필요 → 즉흥 불가 | **즉석 모임** + 즉흥 참여 |
| 처음 만나면 어색함 → 대화 안 됨 | **미션 시스템**으로 어색함을 재미로 전환 |
| 만난 후 연결 끊김 | **점진적 연락처 공개** + 재회 넛지 |
| 외국인은 한국인 만나기 어려움 | **실시간 번역 채팅** + 문화 브릿지 카드 |

### 핵심 컨셉
> "한강에서의 우연한 만남을 설계된 우연(Engineered Serendipity)으로"

- **오프라인 우선**: 이미 같은 물리적 공간에 있는 사람들 연결
- **위치 기반**: 한강 11개 지구 커버, GPS로 "한강근처" 자동 감지
- **어색함 해결**: 미션 타이머가 대화 소재를 제공 ("미션이 시켜서요" = 핑계)
- **안전**: 신뢰도 시스템 + 긴급 신고 + 타임아웃 체크인

## 2. 대략적 제작 계획서

### 기술 스택
| 영역 | 기술 | 비용 |
|------|------|------|
| **앱** | Flutter (iOS/Android/Web 동시) | 무료 |
| **서버** | Node.js (Express) + PostgreSQL + Redis | 카페24 VPS 월 ₩11,000~22,000 |
| **인증** | Firebase Auth (카카오/구글/Apple) | 무료 |
| **실시간** | Socket.io (채팅, 매칭 알림) | 자체 서버 |
| **위치** | 스마트폰 GPS + 거리 계산 | 무료 |
| **지도** | SVG 일러스트 지도 (자체 제작) | 무료 |
| **푸시** | FCM | 무료 |
| **번역** | Google Cloud Translation | 월 50만 자 무료 |

### 개발 로드맵
```
Phase 1 (MVP, 2개월)
├── 위치 기반 사용자 탐색 + 매칭
├── 앱 내 채팅 (그룹 + 1:1)
├── 미션 타이머 (기본 20개)
└── 프로필 + 신뢰도

Phase 2 (3~4개월)
├── 연락처 점진적 공개
├── 외국인 지원 (번역)
├── 리뷰/매너 태그
└── 이벤트 기능

Phase 3 (5~6개월)
├── AI 매칭 고도화
├── 업적 시스템
└── 프리미엄/브랜드 협업
```

### 수익 모델
- **초기**: 모든 기능 무료 (사용자 확보)
- **수익**: 한강 배달/주문 중개 수수료 5~15%
- **보조**: 프리미엄 매칭 (우선 노출), 브랜드 협업

## 3. 세부 계획서

### 3.1 앱 구조 (하단 네비 4탭)
```
홈 | 매칭 | 채팅 | 게시판
```
- **프로필**은 좌상단 햄버거 메뉴에서 접근

### 3.2 전체 페이지 목록 (14개)

| # | 페이지 | 설명 | 네비 |
|---|--------|------|------|
| 1 | **홈** | 히어로 배경 + 번개모임 + 근처사용자 + 게시판/주문 링크 | 독바 |
| 2 | **매칭** | 총 접속자 수 + 필터(지역/취미/관심사/모드) + 사용자 목록 | 독바 |
| 3 | **채팅** | 모임방 목록 + 필터(전체/참여중/1:1) + 아코디언 상세 | 독바 |
| 4 | **게시판** | 자유게시판 목록 + 지역필터 + 익명표시 | 독바 |
| 5 | 게시글 상세 | 본문 + 좋아요 + 댓글 목록 + 댓글 작성 | 뒤로가기 |
| 6 | 게시글 작성 | 제목/내용 + 익명토글 + 지역태그 + 사진 | 닫기 |
| 7 | 프로필 | 사진등록 + 게시판별명 + 신뢰도 + 태그 + 배지 | 뒤로+햄버거 |
| 8 | 사용자 상세 | 매너태그 + 한강온도 + 연락처단계 + 손흔들기/DM | 뒤로가기 |
| 9 | 모집글 작성 | 제목/지역/인원/공개여부/미션선택/미션시간(최대60분) | sticky 헤더 |
| 10 | 그룹 채팅방 | 메시지 + 미션타이머 + 미션제출 | 뒤로가기 |
| 11 | 1:1 채팅방 | DM 메시지 전송 | 뒤로가기 |
| 12 | 한강 지도 | SVG 일러스트 + 9지구 접속자수 + 내위치 | 뒤로가기 |
| 13 | 로그인 | 소셜(카카오/구글/Apple) + 이메일 | 없음 |
| 14 | 회원가입 | 닉네임 + 게시판별명 + 이메일 + 비밀번호 | 뒤로가기 |

### 3.3 핵심 기능 상세

#### 매칭 시스템
- 총 접속자 수 실시간 표시
- 필터: 지역(여의도/뚝섬/반포 등) + 취미 + 관심사 + 모드(놀래요/혼자)
- 각 사용자별 최근 참여 모임 표시
- "한강근처" 배지 (GPS 반경 2km)
- 신뢰도 점수 표시

#### 모임방 시스템
- **공개방**: 누구나 바로 입장
- **비공개방**: 자물쇠 표시 → 아코디언 상세보기 → 손흔들기 → 방장 수락
- 방 안에서 미션 타이머 실행 (사진/음성/텍스트 제출)
- 채팅 필터: 전체 / 참여중 / 1:1

#### 신뢰도 시스템
- 0~100 점수 (기본 50)
- 같은 방 참여자/대화 상대가 +1/-1 투표
- 같은 모임에서 같은 사람에게 1번만 투표 가능
- 닉네임 옆에 "신뢰 78" 형태로 표시

#### 게시판
- 자유게시판 (익명 글쓰기 가능)
- 게시판 전용 별명 (매칭 닉네임과 별도)
- 지역 필터 + 좋아요/댓글

#### 한강 일러스트 지도
- SVG로 한강 물줄기 + 9개 지구 (강북/강남 교차 배치)
- 지구별 접속자 수 표시 (프라이버시: 지구 단위만)
- 내 위치 핑크 애니메이션 마커
- 지구 탭 → 해당 지구 모임방으로 이동

#### 위치 정책
- 누구나 모든 기능 사용 가능 (위치 제한 없음)
- 한강 반경 2km 이내 → "한강근처" 파란 배지 자동 표시
- 한강근처 사용자끼리 우선 매칭
- GPS는 무료 (스마트폰 내장, API 비용 없음)

#### 글자크기 조절
- 햄버거 메뉴에 [-] [+] 버튼
- localStorage에 저장 → 다음 접속 시 자동 적용
- CSS 변수(--fs) 기반 전역 적용
- 기본값: +1 (30대 기준)

### 3.4 데이터 모델 (서버 Prisma)

| 모델 | 설명 |
|------|------|
| User | 닉네임, 게시판별명, 신뢰도, 한강온도, 위치, 활동, mood, hobbies |
| MoimRoom | 모임방 (제목, 지역, 인원, 공개/비공개, 미션) |

| ChatRoom | 1:1 DM (user1, user2) |
| ChatMessage | 채팅 메시지 (1:1 또는 그룹) |
| TrustVote | 신뢰도 투표 (+1/-1, 모임별 1회) |
| BoardPost | 게시글 (익명 여부 포함) |
| BoardComment | 댓글 (익명 여부 포함) |

## 4. 제작 요청 내역 (시간순)

### Phase 0: 초기 기획
1. 한강 중심 커뮤니티 앱 기획
2. 분위기 어색함 해결 시스템 설계
3. 미션 타이머 (JSON 데이터 드리븐)
4. 4단계 연락처 점진적 공개
5. 외국인 지원 (번역, 문화 브릿지)

### Phase 1: 디자인 + HTML 목업
1. 앱 핵심 화면 3종 HTML 목업 + 디자인 토큰
2. v2 퍼플 테마 디자인 3종 + 비교 프리뷰
3. v3 레퍼런스 스타일 디자인
4. **Style D** (Google Material Icons 심플 버전) 채택
5. Style D 색상 진하게 수정

### Phase 2: Flutter 앱 구현
1. Flutter 전체 화면 구현 (Style D, Mock 데이터)
2. 설정 화면 추가
3. 커머스 화면 (배달/편의점/선물하기)
4. 카카오맵 연동
5. 한강 지역별 게시판 추가
6. 법적 문서 (이용약관 + 개인정보처리방침)

### Phase 3: 관리자 + 서버
1. 슈퍼 관리자 디자인 관리 페이지
2. 백엔드 API 서버 (Node.js + Prisma + Socket.io)

### Phase 4: 홈 화면 리디자인
1. 홈 배경이미지 + "한강앱" 타이틀
2. crowny-app.html 통합 (5탭 네비 + 전체 페이지)

### Phase 5: v2 대규모 구조 변경
1. 미션 탭 제거 → 채팅방 안에서 미션 수행
2. 매칭 = 필터 기반 사용자 탐색으로 개편
3. 채팅 = 그룹 모임방 시스템으로 전환
4. 모임방 공개/비공개 + 아코디언 상세보기
5. 모집글 작성 + 그룹 채팅방 + 미션 타이머

### Phase 6: v2.1 기능 확장
1. 하단 네비에 게시판 탭 추가 (프로필→햄버거)
2. 햄버거 드로어 메뉴
3. 검색 기능 (채팅방/사용자)
4. 로그인/회원가입 페이지
5. 1:1 채팅(DM) + 채팅 필터 (전체/참여중/1:1)
6. 게시판 (자유게시판 + 익명 + 별명)
7. 프로필 강화 (사진/별명/신뢰도/태그/배지)
8. 한강 일러스트 지도 (SVG)
9. 게시글 상세보기 + 댓글

## 9. 설계 결정 기록

| 결정 | 선택 | 이유 |
|------|------|------|
| 디자인 스타일 | Style D (Material Icons) | 심플 + 구현 용이 |
| 서버 호스팅 | 카페24 VPS | 고정비, 비용 예측 쉬움 |
| 지도 | SVG 일러스트 (API 아님) | 무료 + 일러스트 느낌 |
| 위치 정책 | 혼합 (누구나 + 한강근처 배지) | 사용자 수 확보 + 현장 우대 |
| 신뢰 시스템 | 참여자 +/- 투표 (Lv 아님) | 실제 만남 기반 평가 |
| 게시판 별명 | 매칭 닉네임과 분리 | 프라이버시 보호 |
| 미션 아키텍처 | JSON 데이터 드리븐 | 서버 수정만으로 미션 추가/삭제 |
| 네비 구조 | 4탭(홈/매칭/채팅/게시판) | 프로필은 햄버거로 이동하여 핵심 기능에 집중 |
| HTML 먼저 | 프로토타입 → Flutter | 빠른 검증 + 수정 용이 |
| 글자크기 | CSS 변수 + localStorage | 접속 시 자동 복원, 연령별 맞춤 |
